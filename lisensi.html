Runtime yang disertakan

Installer menyertakan salinan privat Microsoft .NET Runtime dan Windows Desktop Runtime 8.0.27 untuk x64. Lisensi dan pemberitahuan komponennya ikut dalam folder runtime/LICENSE.txt dan runtime/ThirdPartyNotices.txt. Runtime tersebut tidak mengganti instalasi .NET sistem.

Lirik dan artwork

Lirik tersedia melalui LRCLIB. Artwork dapat berasal dari sesi media Windows, Deezer atau iTunes dan menjadi milik pemegang hak terkait. Layanan tersebut tidak berafiliasi dengan NILO. Baca pemberitahuan pihak ketiga.

Aset visual

Ikon rubah teal berasal dari aset yang diberikan bersama proyek ini. Galeri menampilkan hasil render aplikasi WPF. Lisensi MIT untuk kode tidak mengubah hak atas artwork pihak ketiga.
