Existing optional network behavior is preserved:

- NILO updates (https://nilo.biz.id/aplikasi/release.json): automatic checks after
  startup and every six hours when enabled; manual checks and installer download
  from the same origin. Requests include a NILO-Updater user-agent. Settings,
  Shelf contents, song metadata and browser tabs are not sent for update checks.
  Downloads are verified against release size, SHA-256 and file metadata. These
  integrity checks do not represent an Authenticode signature; installers are
  still unsigned. Installation begins only after the user's explicit action.

- LRCLIB (https://lrclib.net): song title, artist, album and duration are sent to
  retrieve synchronized lyrics.
- Deezer (https://developers.deezer.com): title/artist searches for fallback artwork.
- iTunes Search API (https://performance-partners.apple.com/search-api): fallback
  title/artist searches and artwork URLs.
- Artwork is owned by its respective rights holders and displayed as media
  metadata. These services are not affiliated with or endorsing NILO.

The application has no analytics/account service. Turning off media notifications
does not disable metadata lookups. Media controls depend on the source application's
Windows media session support. File shelf entries reference existing local paths;
removing an entry never deletes the original file.
