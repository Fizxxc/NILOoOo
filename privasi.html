Situs web

Situs ini tidak memasang cookie, analitik, atau pelacak pihak ketiga. Gambar, font sistem, skrip, informasi rilis dan installer diakses dari situs ini. Galeri menampilkan gambar aplikasi dan tidak mengakses media atau file komputer Anda.

Penyedia hosting dapat menyimpan log permintaan HTTP, termasuk alamat IP, informasi browser, waktu, dan file yang diminta. Kebijakan log mengikuti hosting yang digunakan.

Installer

Installer membawa aplikasi dan runtime privat di dalam file yang sama. Installer tidak mengunduh dependensi, tidak membuat akun, dan tidak mengirim telemetri. Pemasangan menulis file di %LOCALAPPDATA%\Programs\NILO, membuat shortcut Start Menu, dan mendaftarkan aplikasi pada daftar Apps Windows untuk pengguna saat ini.

Uninstall mempertahankan pengaturan dan riwayat di AppData serta file tambahan atau file instalasi yang sudah diubah pengguna. Pembaruan menyimpan folder instalasi sebelumnya sebagai cadangan.

Data aplikasi

Pengaturan dan riwayat air disimpan lokal di %APPDATA%\Vyra untuk kompatibilitas. Referensi Shelf bersifat sementara selama sesi aplikasi dan tidak mengunggah file. Informasi media, audio, baterai dan layar dibaca dari API Windows untuk fitur aplikasi.

Mode adaptif membaca perubahan jendela aktif dan posisi kursor untuk menyimpan atau memunculkan notch. Dock opsional membaca nama aplikasi Start Menu dan judul jendela berjalan. Sematan dan daftar aplikasi yang dibuka melalui NILO disimpan lokal dalam pengaturan. Data ini tidak dikirim untuk pembaruan.

Pemeriksaan pembaruan

Jika pemeriksaan otomatis aktif, NILO meminta informasi versi dari https://nilo.biz.id/aplikasi/release.json setelah startup dan setiap enam jam. Server menerima informasi koneksi seperti alamat IP dan user-agent NILO-Updater. Aplikasi tidak mengirim riwayat air, file Shelf, judul jendela atau daftar tab browser untuk memeriksa update.

Installer baru diunduh setelah Anda memilih Unduh update dan disimpan di subfolder updates dalam folder data aplikasi. Pemasangan dimulai setelah Anda memilih Pasang & mulai ulang. Pengaturan pemeriksaan otomatis dapat dimatikan di Settings. Mode adaptif tidak mencadangkan strip layar permanen. AppBar tetap tersedia pada mode reservasi lama jika mode adaptif dimatikan. NILO tidak membaca URL atau isi tab untuk menyediakan ruang di atas layar.

Pencarian lirik dan artwork

Pencarian lirik dapat mengirim judul lagu, nama artis, album dan durasi ke LRCLIB. Metadata judul/artis dapat dipakai untuk pencarian artwork melalui Deezer dan iTunes. Layanan ini juga menerima informasi koneksi seperti alamat IP. Mematikan notifikasi media tidak otomatis menonaktifkan pencarian metadata.

Kontak

Tautan email membuka aplikasi email Anda. Pesan baru dikirim setelah Anda mengirimkannya sendiri. Jangan sertakan kata sandi atau data pribadi yang tidak diperlukan dalam laporan masalah.
